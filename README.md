# 🌸 Bienestar Flow

**Bienestar Flow** は、タスク管理と習慣トラッキングを組み合わせたシンプルで親しみやすいウェブアプリです。

毎日の「やること」と「続けたい習慣」を一緒に管理して、充実した日々を応援します。

## ✨ 特徴

### タスク管理
- 📅 **日付・時刻管理** — 今日、明日、先の予定を整理
- 🏷️ **カテゴリ分類** — Work、Personal、Study、Health で整理
- ⚡ **優先度設定** — 高・中・低で優先順位を管理
- 📝 **メモ機能** — タスクに詳細メモを追加
- ✅ **完了追跡** — 完了したタスクを記録

### 習慣トラッキング
- 🔥 **ストリーク管理** — 連続達成日数を表示
- 📊 **統計情報** — 達成率、最長記録を追跡
- 📅 **カスタム頻度** — 毎日、平日、週末、カスタムに対応
- 🎨 **アイコン選択** — 8種類のアイコンから選択可能
- 📈 **カレンダービュー** — 月ごとの達成状況を視覚化

### その他の機能
- 🎭 **キャラクター表示** — 8種類の動物キャラクターが励ましてくれる（毎日ランダムまたは固定）
- 🌙 **テーマ対応** — ライト・ダーク・システムテーマから選択
- 💾 **データエクスポート/インポート** — JSON形式でバックアップ・復元
- 🔔 **通知機能** — タスク期限のリマインダー（ブラウザ通知）
- 📱 **モバイル対応** — スマートフォンでも快適に使用可能

## 🚀 使い方

### インストール
1. このリポジトリをクローン：
   ```bash
   git clone https://github.com/YOUR_USERNAME/ToDo-Habits.git
   cd ToDo-Habits
   ```

2. `index.html` をブラウザで開く：
   ```bash
   # Windows
   start index.html
   
   # macOS
   open index.html
   
   # Linux
   xdg-open index.html
   ```

### 基本的な使い方

**タスク追加：**
- ホーム画面の「Quick Add」フォームから素早く追加
- または「Add task」ボタンで詳細を設定

**習慣追加：**
- 「Habits」ビューの「Add habit」ボタンから追加
- 頻度（毎日・平日・週末・カスタム）を選択

**進捗管理：**
- チェックボックスをクリックで完了/未完了を切り替え
- 進捗バーでその日の完了状況を確認

**データバックアップ：**
- Settings → Data から「書き出す」で JSON ファイルを保存
- 別の端末から復元する場合は「読み込む」を使用

## 🛠️ 技術

- **フロントエンド：** HTML5、CSS3、Vanilla JavaScript
- **ストレージ：** ブラウザ localStorage（ローカル保存）
- **ブラウザ対応：** Chrome、Firefox、Safari、Edge など最新ブラウザ

## 💾 データ保存

- すべてのデータはブラウザの localStorage に保存されます
- サーバー不要で、オフラインでも使用可能
- ブラウザのキャッシュをクリアするとデータが削除されるため、定期的にバックアップしてください

## 🎨 デザイン

**色彩：**
- クリーム色ベースの明るいUI
- コーラルオレンジのアクセントカラー
- ダークブラウンのテキスト
- ダークモード対応

**キャラクター：**
- 8種類の可愛らしい動物キャラクター
- 毎日の進捗に応じたメッセージ表示
- ユーザーを励まし、モチベーション維持をサポート

## 📋 ビュー

| ビュー | 説明 |
|-------|------|
| **Home** | 今日のタスク・習慣・ストリークを一覧表示 |
| **Inbox** | 日付未定のタスクを管理 |
| **Upcoming** | 明日以降の予定を表示 |
| **Habits** | 習慣の詳細情報と統計を表示 |
| **Completed** | 完了したタスクの履歴 |
| **Settings** | テーマ、キャラクター、カテゴリー、通知、データ管理 |

## 🔐 プライバシー

- このアプリはサーバーにデータを送信しません
- すべての情報はあなたのデバイスに保存されます
- データの所有権はあなたにあります
